# 🎮 Agarz Pro v2 - Virus Hunter

Agarz.com için akıllı virus kasma, makro ve otomasyon sistemi.

## 📥 Kurulum

1. Chrome'da `chrome://extensions/` aç
2. Sağ üstte **Geliştirici Modu** aç
3. **Paketlenmemiş Uzantı Yükle** tıkla
4. Bu klasörü seç

## 🚀 Kullanım

1. `agarz.com` aç
2. Sağ altta 🎮 buton tıkla
3. **▶ BAŞLAT** ye tıkla
4. Virüsler otomatik takip edilecek

## ✨ Özellikler

- ✅ Canvas `arc` interception ile virus tespiti
- ✅ Otomatik virus takibi
- ✅ Makro butonları (E, Space)
- ✅ Overlay göstergeler (pulse animasyon)
- ✅ Modern gradient UI
- ✅ Ayarları kaydeder (chrome.storage)
